# Webhooks outbound

Gallo hace `POST` a tu URL HTTPS. Firma: HMAC-SHA256.

**Fuente de verdad:** el POST. **Red de seguridad:** `GET /v1/webhook-events` (mismo envelope) + `GET /v1/movements` (ledger). No iterés CVUs.

## Headers

| Header | Descripción |
|--------|-------------|
| `X-Gallo-Signature` | HMAC-SHA256 hex de `${timestamp}.${body}` |
| `X-Gallo-Timestamp` | Unix segundos |
| `X-Gallo-Event-Id` | Idempotencia receptor |
| `X-Gallo-Event-Type` | Tipo de evento |

Secret: `whsec_…`.

```json
  "eventId": "d290f1ee-6c54-4b01-90e6-d701748f0851",

  "data": {

    "externalId": "aviso-credito-…",
    "cvuDebito": "0000208200000000000291",
    "cuitDebito": "20370994049",
    "titularDebito": "JUAN PEREZ"

```

Cash-in es **un solo** evento: `account.credited` con payload completo. No hay ping vacío + segundo mensaje.

## Verificar firma (Node.js)

```js
const crypto = require('crypto');

function verify(req, secret) {
  const ts = req.headers['x-gallo-timestamp'];
  const sig = req.headers['x-gallo-signature'];
  const body = req.rawBody; // crudo, sin re-serializar
  const expected = crypto
    .createHmac('sha256', secret)
    .update(`${ts}.${body}`)
    .digest('hex');
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(sig));
}
```

Rechazá timestamps &gt; ~5 min.

## Poll / catch-up (outbox)

```bash
curl "https://api.dev.gallo-pay.com/v1/webhook-events?limit=100" \
  -H "x-api-key: gpk_test_…"

# siguiente página
curl "https://api.dev.gallo-pay.com/v1/webhook-events?cursor=<nextCursor>&limit=100" \
  -H "x-api-key: gpk_test_…"
```

Respuesta: `{ items, nextCursor, limit }`. Cada ítem = mismo envelope del POST + `deliveryStatus` / `attempts` / `lastError`.

- Lista **todos** los tipos que Gallo POSTea (`account.*`, `transfer.*`, `debin.*`, `qr.*`, `promo.*`, …).
- `updated_since` (ISO) filtra por `occurredAt`.
- `GET /v1/webhook-events/:id` — un evento.
- `POST /v1/webhook-events/:id/replay` — reencola (mismo `eventId`; no resetea `attempts`; bypasea el tope de reintentos automáticos).

### Breaking (live 2026-09-15)

Antes, `GET /v1/webhook-events` listaba avisos inbound de Coinag. Eso se movió a **`GET /v1/bank/inbound-events`**. Pedidos legacy (`type=aviso_credito_cvu`, `/summary`) responden **410** con `movedTo`.

```bash
curl "https://api.dev.gallo-pay.com/v1/bank/inbound-events?limit=50" \
  -H "x-api-key: gpk_test_…"
```

Summary ops: `GET /v1/bank/inbound-events/summary`.

## Dedupe con el ledger

Un cash-in aparece como:

1. `account.credited` en el outbox / POST, y
2. una fila `credit` en `GET /v1/movements`

**No** son dos eventos de outbox. Mergeá por `idCoelsa` (cash-in) o `eventId` / `transferId` (resto).

## Retries

Respondé **2xx** rápido. Ante fallo: **8 intentos**, backoff 30s → 2h. El body se reconstruye desde el outbox (mismo `eventId`). Deduplicá con `X-Gallo-Event-Id`.
